# Animated Mic

This project is a **voice-powered web interface** where clicking the glowing microphone button allows users to speak, and the system automatically converts speech to text and performs a **Google search** based on the spoken query.  

It’s a simple yet powerful demo of **Web Speech API** and **animated UI design** using HTML, CSS, and JavaScript.


##  Features
-  Animated glowing microphone button (HTML + CSS only)
-  Voice recognition powered by **Web Speech API**
-  Automatic Google search redirection
-  Lightweight — no external libraries required
-  Works directly in modern browsers (Chrome recommended)

##  Technologies Used
- **HTML5** – Structure  
- **CSS3** – Styling & animation (glowing mic button)  
- **JavaScript (ES6)** – Logic for speech recognition and redirection  
- **Web Speech API** – Voice input handling
